# Playwright Employee Management Automation

End-to-end test automation framework for the Employee Management System using Playwright and JavaScript.

## 🧪 Automation

This project covers:

- Employee creation
- Employee list validation
- Employee details validation
- Employee profile image upload
- Employee JSON download
- Positive and negative scenarios
- Dynamic employee code handling
- Cross-browser testing
- Screenshots and trace collection
- Playwright Page Object Model (POM)
